# Tradução de termos: fale a língua do dono

O dono do negócio sabe o que quer, mas não a palavra técnica. A IA nunca deve
despejar jargão numa entrevista. Traduza SEMPRE para o dia a dia, e quando
precisar oferecer uma opção técnica, explique com uma analogia + vantagem +
desvantagem.

| Termo técnico | Como dizer para o dono |
|---|---|
| Login / Autenticação | "entrar com usuário e senha" |
| OAuth / SSO | "entrar com a conta do Google/Apple (login social)" |
| Cadastro / Sign-up | "criar a conta na primeira vez" |
| Banco de dados | "onde as informações ficam guardadas" |
| API / Integração | "fazer dois sistemas conversarem (ex.: seu site puxar do seu estoque)" |
| Webhook | "um aviso automático que dispara quando algo acontece" |
| Backend / Servidor | "a parte que roda 'nos bastidores', que o usuário não vê" |
| Frontend / Interface | "as telas que a pessoa vê e clica" |
| Deploy / Publicar | "colocar no ar para as pessoas usarem" |
| Hospedagem | "onde o sistema fica 'morando' na internet" |
| Responsivo | "se ajusta à tela do celular e do computador" |
| Notificação push | "aviso que aparece no celular" |
| CRUD | "cadastrar, ver, editar e apagar registros" |
| Relatório / Dashboard | "um painel que mostra os números de forma fácil" |
| Fila / Processamento assíncrono | "tarefa que roda no fundo sem travar a tela" |
| Cache | "guardar o resultado pronto para carregar mais rápido" |
| Criptografia | "embaralhar o dado para ninguém ler se vazar" |
| LGPD / Dados sensíveis | "regras para tratar dado pessoal com cuidado" |
| Permissões / Papéis | "quem pode ver/fazer o quê (dono, funcionário, cliente)" |
| Escalabilidade | "aguentar crescer sem parar de funcionar" |
| Uptime / Disponibilidade | "ficar no ar sem cair" |
| MVP | "a primeira versão útil, com o essencial funcionando" |

## Regra da pergunta
Quando oferecer uma escolha técnica, coloque a **recomendada primeiro** e descreva
cada opção com três coisas: **o que é + a vantagem + a desvantagem**. Ex.:

> Como as pessoas vão entrar?
> - **Login social (recomendado)** — entra com a conta do Google. Vantagem: nada de
>   guardar senha. Desvantagem: depende do Google estar no ar.
> - **Usuário e senha** — você controla tudo. Desvantagem: precisa cuidar de "esqueci
>   a senha", segurança etc.

O dono lê a explicação e **só escolhe**. Ele não precisa saber a palavra "OAuth" —
precisa entender o trade-off.
