# As três réguas de satisfação — guia rápido (sem jargão)

Este guia é para o Pulso consultar ao interpretar as notas e explicá-las ao dono.

## NPS — Net Promoter Score ("o quanto me recomendaria")

- **Pergunta:** "De 0 a 10, o quanto você indicaria a gente a um amigo ou colega?"
- **Como se lê a resposta:**
  - **9-10 = Promotor** — cliente leal, vira boca a boca.
  - **7-8 = Neutro** — satisfeito mas não engajado; não conta na nota.
  - **0-6 = Detrator** — insatisfeito, risco de falar mal.
- **Conta:** `NPS = % de promotores − % de detratores`. Vai de **−100 a +100**.
- **Faixas para explicar ao dono (referência para serviço no Brasil):**
  - **acima de +50** 🟢 excelente — sua base te promove sozinha.
  - **entre 0 e +50** 🟡 na média — tem promotor, mas há o que melhorar.
  - **abaixo de 0** 🔴 crítico — mais gente falando mal do que bem; prioridade máxima.
- **Quando usar:** para a saúde geral do relacionamento, medida de tempos em
  tempos (mensal ou trimestral). É a régua "guarda-chuva".

## CSAT — Customer Satisfaction ("o quanto ficou satisfeito")

- **Pergunta:** "De 1 a 5, o quanto você ficou satisfeito com [o atendimento / a
  entrega / a consulta]?"
- **Como se lê:** satisfeito = deu **4 ou 5** (as duas notas do topo).
- **Conta:** `CSAT = % de respostas que foram 4 ou 5`.
- **Faixas:** acima de **80%** 🟢 forte · **60-80%** 🟡 ok · abaixo de **60%** 🔴 fraco.
- **Quando usar:** logo após um evento específico — um atendimento, uma entrega,
  um suporte. Mede aquele momento, não o relacionamento inteiro.

## CES — Customer Effort Score ("o quão fácil foi")

- **Pergunta:** "De 1 a 7, o quão fácil foi resolver o que você precisava?"
  (7 = muito fácil, 1 = muito difícil).
- **Como se lê:** olhe a **média**. Quanto mais alta, menos esforço o cliente teve.
  6-7 = fácil · 1-3 = difícil (atrito alto).
- **Quando usar:** para achar atrito num processo — abrir chamado, fazer a
  primeira compra, cancelar, instalar. Esforço alto é o que mais gera detrator.

## Regras de bolso para o Pulso

- **Nunca compare escalas diferentes como se fossem a mesma coisa.** NPS não é %,
  CSAT é %, CES é média. Deixe claro qual régua está na tela.
- **Volume importa.** Uma nota de 3 respostas é um palpite; a partir de ~20-30
  respostas ela começa a significar algo. Sempre diga o tamanho da base.
- **A nota isolada não age — o comentário sim.** O número diz *se* há problema;
  a pergunta aberta diz *qual*. Por isso toda pesquisa tem uma pergunta aberta.
- **Detrator é ativo, não arquivo.** Todo detrator vira uma tarefa de recuperação,
  não uma linha na planilha. O maior ganho de NPS vem de recuperar quem reclamou.
- **Promotor é semente de prova social.** Quem deu 9-10 é o depoimento e a
  indicação que você ainda não pediu.
