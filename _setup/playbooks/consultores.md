# Playbook FlowOS Pro para Consultores e Prestadores de Serviço

**Para:** consultores, coaches, contadores, advogados, designers, desenvolvedores, freelancers e qualquer prestador de serviço intelectual.

**Antes de começar:** este playbook usa agentes dos pacotes **Clientes** e **Gestão**. Se não ativou no `/instalar`, roda `/pacotes` e liga os dois.

---

## Os 3 agentes que mudam o jogo para você primeiro

### 1. Amarra: proposta que fecha sem precisar de reunião extra

(pacote Clientes: ative com `/pacotes`)

Consultor que manda proposta clara fecha mais do que quem é melhor tecnicamente mas se comunica mal. A Amarra prepara a reunião de descoberta, guarda a dor do cliente nas palavras dele e monta uma proposta consultiva com 3 opções. Preço ela não inventa: os valores vêm de você.

**Preparando a reunião de descoberta:**
```
/Amarra vou ter reunião de descoberta com uma [tipo de empresa] de [porte]. Monta o roteiro de perguntas.
```

**Proposta de consultoria:**
```
/Amarra fiz a reunião com [cliente]. O que eles disseram: [problema, impacto, prazo, quem decide].
Monta a proposta de consultoria [área] com 3 opções.
Meus preços: [valor de cada opção]
```

**Follow-up de proposta sem resposta:**
```
/Amarra mandei proposta há 3 dias e o cliente não respondeu. Monta um follow-up sem pressão.
```

---

### 2. Alavanca: transforma expertise em produto que escala

Todo consultor chega num teto de horas. A Alavanca transforma o que você sabe em produto que vende enquanto você está dormindo.

**Definindo o produto:**
```
/Alavanca sou consultor de [área]. Quero criar algo que escale meu conhecimento. Me ajuda a definir o produto certo.
```

**Estruturando uma mentoria:**
```
/Alavanca quero criar uma mentoria de [X meses] para [público]. Estrutura os módulos e o resultado esperado.
```

**Precificando corretamente:**
```
/Alavanca cobro R$300/hora em consultoria 1:1. Quanto cobro por uma mentoria em grupo de 8 semanas?
```

---

### 3. Vitrine: relatório de resultado que justifica a renovação do contrato

Cliente renova quando percebe valor. O Vitrine faz esse valor ficar visível.

**Relatório mensal:**
```
/Vitrine monta relatório de resultado do mês para o cliente [nome]
O que foi feito: [lista]
Resultados: [métricas ou conquistas]
Próximos passos: [o que vem no próximo mês]
```

**Apresentação para renovação:**
```
/Vitrine vou apresentar resultados do trimestre para justificar renovação. Monta a estrutura da apresentação.
```

## Exemplos práticos por situação

**Dificuldade em precificar o serviço:**
```
/Farol cobro R$X/hora, tenho [N] horas disponíveis por mês. Meus custos fixos são R$Y. Preciso de quanto em contratos?
```

**Preparando call de diagnóstico com prospect frio:**
```
/Fisga vou ter call de diagnóstico com prospect amanhã. É uma [tipo de empresa]. Monta o roteiro de perguntas.
```

**Onboarding de cliente novo:**
```
/Cais fechei consultoria com o cliente [nome]. Serviço: [tipo]. Monta as boas-vindas, o questionário inicial e o combinado de escopo.
```

**Diagnóstico de IA para oferecer ao cliente:**
```
/Sextante quero avaliar se a empresa do meu cliente [nome] está pronta para usar IA. Conduz o diagnóstico e monta o relatório com o roadmap.
```

**Decisão difícil:**
```
/Fulcro um cliente quer me contratar, mas pede exclusividade e paga abaixo do que costumo cobrar. Me ajuda a pensar se aceito.
```

**Conteúdo de autoridade:**
```
/Holofote quero ser referência em [especialidade] no LinkedIn. Que tipo de conteúdo constrói isso?
```

**Quando o cliente pede desconto:**
```
/Amarra o cliente pediu 20% de desconto na minha proposta de R$X. Como respondo valorizando o trabalho?
```

## Precificação: o erro mais comum do consultor

Se você está sempre ocupado mas não sobra nada no fim do mês, o problema é precificação.

```
/Farol trabalho sozinho, tenho 20 horas disponíveis por semana para clientes. 
Custos fixos: R$[X]/mês. Quero R$[Y] líquido por mês. Quanto devo cobrar por hora?
```

O Farol calcula e te mostra o número real.
